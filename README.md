Ziel des Projekts:

Das Ziel unseres Projekts ist es eine Website zu programmieren die es ermöglicht in einer interaktiven Map, Informationen über Wanderouten aufzurufen.
Wichtig hierbei ist es eine möglichst simple und bugfreie Oberfläche zu kreiiren anstelle von möglichst vielen optionen.
Das erreichen wir durch wiederholtes reviewen der jeweiligen Sprints.
Wenn es die Zeit hergibt und das Projekt perfekt optimiert ist, wäre es möglich einen Wintermodus zu integrieren der verwendet werden kann um Skigebiete auf der Karte aufzurufen.
